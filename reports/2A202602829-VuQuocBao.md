2. **Quyết định:** Chunk 500 ký tự, overlap 50, separators `["\n\n", "\n", ". ", " ", ""]`; kèm fallback hashing 384 chiều khi thiếu API key.
   **Lý do/evidence:** 500 ký tự ≈ một khoản/điểm văn bản pháp luật nên retrieval chính xác, context gửi LLM gọn. Fallback giúp pipeline và test chạy được khi chưa có key (`_resolved_embedder_name()`).
   **Trade-off:** Chunk theo ký tự có thể cắt giữa Điều/khoản; hashing 384 chiều khác chiều OpenAI 1536 nên phải xóa collection và index lại khi đổi provider (`reset_collection()`, chạy `reset=True`).
